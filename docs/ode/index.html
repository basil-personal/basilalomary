06 / THE FIRST 30 DAYS

The first 30 days will identify avoidable delays
and establish whether the project pays back

Proposed sample: 5–8 franchisees, 20–30 recent openings and 5–10 active projects across different markets

DAYS 01–07

Map the work

Interview owners, architects, GCs and the corporate team. Secure schedules, correspondence, invoices and approval histories.

Output: dated project histories
DAYS 08–15

Quantify the bottlenecks

Separate active work, avoidable waiting and external constraints. Identify the critical path and cost of each delay.

Output: days and costs by cause
DAYS 16–23

Test past cases

Test document checks, issue routing and schedule updates on completed projects; validate on cases held out from development

Output: prototype + error analysis
DAYS 24–30

Agree the investment

Select pilot stores and owners. Finance validates eligible openings, sales assumptions and the cost to deliver

Output: pilot scope and investment decision
MEASURE AGAINST COMPARABLE PROJECTS

Match projects by market, format and stage. Track critical-path days saved, operator effort and accuracy of extracted dates and actions

SET SCALE / STOP RULES BEFORE THE PILOT

Set time-saving and accuracy thresholds before launch. Scale with verified net benefit and operator use; hold build cost, quality and readiness standards
